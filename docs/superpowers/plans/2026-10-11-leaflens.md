# LeafLens Implementation Plan

> For agentic workers: use superpowers:executing-plans inline, task by task.

**Goal:** A polished, honest crop disease diagnosis project with reproducible CNN/VGG16 comparison.
**Architecture:** React frontend calls FastAPI. ML modules own splits, models, training, evaluation and Grad-CAM. Filesystem artifacts supply model readiness and measured metrics.
**Tech Stack:** React, Vite, Python, PyTorch, FastAPI, pytest, Playwright.
**Spec:** ../specs/2026-10-11-leaflens-design.md

## Global constraints
All work in leaflens; preserve Git identity; no fabricated metrics; no dataset/checkpoints in Git; responsive and keyboard accessible UI.

## Review focus
Invalid/oversized/non-image upload; absent model; duplicate leakage; class mismatch; UI failures on narrow screens.
